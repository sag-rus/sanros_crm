# САНАТА: правила изменения и установки кода CRM

- Все изменения CRM выполнять только в репозитории `/Users/rustemsagdiev/sanrussia/crm`. Ветки и коммиты создавать здесь. Отдельные клоны, копии и worktree для изменений CRM запрещены без прямого разрешения пользователя. Если запись недоступна, сообщить о блокировке.
- Все изменения кода, шаблонов, схемы БД, скриптов и несекретной конфигурации сохранять в Git. До установки на сервер сделать коммит и push в соответствующий репозиторий.
- Устанавливать обновления на сервер только через Git: получить опубликованный коммит и применить штатным Git-процессом. Проверять и сообщать установленный коммит.
- Не заменять рабочие файлы напрямую через SSH, SCP, SFTP, rsync, tar, редактор или скрипт вместо Git. SSH разрешён для Git, проверок и предусмотренных версионируемых миграций.
- При отсутствии Git-доступа установка блокируется до восстановления доступа. Прямая загрузка файлов не является обходным решением.
- Перед установкой проверить ветку, незакоммиченные изменения и соответствующие тесты. Не затирать чужие изменения и не включать их в свой коммит. Не применять reset --hard, clean или принудительный push для обхода конфликтов.
- Пароли, токены, приватные ключи и другие секреты не коммитить. В Git хранить безопасные примеры и инструкции; рабочие секреты хранить вне отслеживаемого кода.
- Базу данных и пользовательские данные не коммитить. Изменения структуры и необходимые миграции должны быть версионированы.
- Материалы локального зеркала проекта в sources/ и другие синхронизируемые справочные файлы не изменять.

Исключения требуют прямого разрешения пользователя для конкретного действия.
