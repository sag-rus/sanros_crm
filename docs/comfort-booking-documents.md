# Документы гостей Comfort Booking

Поля редактора брони: дата рождения, паспорт, кем выдан и дата выдачи для заказчика и гостей; свидетельство о рождении только для гостей. Поля необязательные. Сохраняются обычным подтверждением изменения брони.

Источник данных — `_cb_documents` внутри JSON брони сайта. CRM получает их через подписанный внутренний API и использует в памяти при формировании обоих договоров и ваучера. В `klient` и `payer` эти поля не записываются. Юридическое лицо, выбранное плательщиком, сохраняется; данные заказчика выводятся отдельно.

В ответах протокола TravelLine поля отсутствуют: сериализаторы используют разрешённый перечень полей. Данные документов не добавляются в историю операций. Предпросмотр хранится только на сайте в существующей таблице предварительных изменений.

Ваучер доступен в меню документов после подтверждения текущей версии брони TravelLine. Проверка действует и при прямом запросе документа. Для обычных заявок сохраняется прежняя обменная путёвка.

Установка: сначала коммит сайта, затем CRM, только через Git master. Миграция БД не нужна. Версия CRM обновляется в index.php. Проверки сайта: tests/comfort-booking-documents.php и tests/comfort-booking-site.php. Проверки CRM: tests/comfort-booking-documents.php, tests/comfort-booking-request-state.php, tests/comfort-booking-reservations.php и tests/comfort-booking-reservations-ui.js. Для проверки старого PDF-движка на PHP 7: php tests/comfort-booking-documents.php --pdf (только вымышленные данные, без БД/API).
