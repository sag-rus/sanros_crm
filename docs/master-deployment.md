# Единая ветка master — 04.11.2026

Актуальное установленное содержимое сохранено в master вместе с историей опубликованных рабочих веток. Предыдущие ветки не удалены. Новые изменения выполнять только в master.

Перед изменениями: `git status`, `git switch master`, `git pull --ff-only origin master`. После проверок: коммит и `git push origin master`.

На сервере: проверить отсутствие незакоммиченных изменений исходников, затем `git fetch origin master`, `git switch master`, `git merge --ff-only origin/master`; проверить SHA и работоспособность. При расхождении остановиться и сверить изменения. Не использовать cherry-pick для обычной установки, force push, reset --hard или прямую замену исходников.

Секреты, БД, журналы, пользовательские файлы и резервные копии не включать в Git.
