## Установка

Только из опубликованной `master`, после `git fetch origin master` и `git merge --ff-only origin/master` в штатной серверной копии. Исходники должны быть без локальных изменений.

```sh
sudo python3 tools/disable-obsolete-jobs.py
sudo python3 tools/disable-obsolete-jobs.py --apply
sudo python3 tools/disable-obsolete-jobs.py
```

Первый запуск выводит план. Второй применяет только перечисленные в `deploy/obsolete-jobs.json` отключения. Последний должен показать пустой список изменений. Повторное применение безопасно и не создаёт новую резервную копию, если всё уже отключено.

Перед изменениями создаётся приватный каталог `/var/backups/sanata-job-retirement/<migration>-<suffix>` (0700) с исходным и итоговым crontab, манифестом и SHA коммита. Файлы — 0600. Остальные строки crontab сохраняются побайтно, включая комментарии. Неизвестное расписание для целевой команды, изменившаяся конфигурация или незакоммиченные исходники останавливают установку.

После установки проверить `crontab -u <пользователь> -l`, отсутствие целевых заданий и неизменность остальных. Проверить `completed.json` в резервной копии. При частичном сбое программа сообщает каталог резервной копии и не затирает изменения администратора; повторный план покажет оставшиеся действия. Восстановление исходных заданий требует отдельного решения и проверенной версионируемой миграции с использованием файлов `.before`.

Проверка без изменения системы: `python3 tests/obsolete-jobs.py`. Тесты проверяют сохранение других заданий, повторный запуск, неожиданные изменения расписания и защиту от отключения посторонних программ Supervisor.
